GTFS ↔ NeTEx comparability

MVD Monitor

Each run resolves the newest published GTFS and NeTEx release for every country below, downloads both, and recomputes stop and route comparability using the Minimum Viable Denominator method. Two rates are reported per dimension, one per side.

Method: Miclaus & Sohi, It is Not the Standard, It is the Feed, Sem4Tra 2026. Source and results: github.com/DataFan2/gtfs-netex-mvd-comparison
